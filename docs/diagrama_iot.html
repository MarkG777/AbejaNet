Flujo de Datos IoT en Tiempo Real

sequenceDiagram
    autonumber
    participant S as Sensores (Colmena)
    participant MC as Microcontrolador
(ESP32)
    participant MQ as Broker MQTT
    participant API as API Backend
    participant DB as Base de Datos
    participant FCM as Firebase Cloud
Messaging
    participant APP as App Móvil
(Apicultor)
    participant WEB as Web Admin

    S->>MC: Lecturas cada 5 min
(temp, humedad, sonido)
    MC->>MQ: Publica a tema
abejanet/colmena/{id}/sensores
    MQ->>API: Suscripción recibe payload
    API->>DB: INSERT INTO lecturas_sensores
    API->>API: Evalúa umbrales críticos
    alt Condición crítica detectada
        API->>FCM: Envía notificación push
        FCM->>APP: 🚨 Alerta: Temperatura alta en Colmena #3
        API->>WEB: Actualiza dashboard en tiempo real
(WebSocket / SSE)
    else Todo normal
        API->>WEB: Actualiza gráficos de métricas
    end
    APP->>API: GET /api/colmena/{id}/historial
    API->>DB: SELECT * FROM lecturas
WHERE colmena_id = {id}
    DB->>API: Resultados JSON
    API->>APP: Historial de sensores (24h, 7d, 30d)
    WEB->>API: GET /api/admin/reportes
    API->>DB: Consulta agregada
    DB->>API: Datos agrupados
    API->>WEB: Reporte CSV / PDF / Gráfico
