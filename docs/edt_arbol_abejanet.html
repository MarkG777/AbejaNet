Descripción: Esta EDT representa el proyecto AbejaNet como un sistema completo compuesto por aplicación móvil, panel web administrador e integración IoT. El administrador del negocio controla la página web para gestionar colmenas, usuarios, roles, contraseñas, reportes y alertas. El sistema IoT recopila información de las colmenas mediante sensores y la envía al backend para ser consultada desde la app móvil y el panel web.
